Stateless access / RFC 7519

Токени замість сесій.

REST API перевіряє підпис HS256, термін дії та тип токена на кожному запиті. Access Token живе 15 хвилин, Refresh Token — 7 діб і ротується одноразово. Повторне використання старого Refresh-токена відкликає всю родину токенів.

Протокол перевірки

/api/v1
  1. 01
    Випустити пару токенів POST /auth/login
  2. 02
    Профіль із Access Token GET /user/profile · Bearer
  3. 03
    Запит без токена GET /user/profile · без Authorization
  4. 04
    Підмінити роль на admin той самий підпис, змінений Payload
  5. 05
    Ротувати Refresh-токен POST /auth/refresh · один раз
  6. 06
    Повторно використати старий Refresh очікується 401 + revoke родини

Усі запити виконуються з браузера через fetch до реального API. Пароль не зберігається: він використовується лише для обміну на токени.

Підпис, а не довіра

Payload можна прочитати, але зміна будь-якого поля робить підпис недійсним. Сервер відхиляє такий токен до виконання бізнес-логіки.

{{ icon('key') }}

Короткий Access TTL

15 хвилин обмежують вікно атаки у разі викрадення Access-токена. Довший доступ видається лише через ротований Refresh-токен.

{{ icon('alert') }}

Reuse detection

Кожен Refresh-токен одноразовий. Повторна спроба обміну означає компрометацію — вся родина токенів миттєво відкликається.
