Sigil / asymmetric signature

Підпис, який переживе копіювання файлу.

Приватний ключ RSA-2048 підписує SHA-256-дайджест документа; відкритий ключ дозволяє перевірити авторство, не розкриваючи приватний ключ. Навіть якщо файл скопіювати, змінити один байт або підмінити підпис, перевірка поверне False / InvalidSignature.

04 · VERIFY

Відкритий ключ

Перевірка підпису + SHA-256. Невдача → відмова у видачі.

Життєвий цикл ключа

Генерація
RSA-2048, public exponent 65537, локально на сервері.
Приватний ключ
PKCS#8 PEM, BestAvailableEncryption(passphrase); парольна фраза не зберігається.
Відкритий ключ
X.509 SubjectPublicKeyInfo PEM; fingerprint = SHA-256(SPKI DER).
Зберігання
таблиця user_signing_keys: public PEM, encrypted private PEM, fingerprint.
Ротація
новий ключ стає active; старі ключі лишаються для перевірки старих підписів.
Public PEMМожна публікувати. Використовується для verify.
Private PEMЛише encrypted. Без passphrase — непридатний.

Висновок: ЕЦП додає до конфіденційності AES-GCM ще й авторську цілісність і неспростовність. RSA-PSS + SHA-256 + encrypted PKCS#8 дають практичний баланс для навчального проєкту; у production відкриті ключі слід закріпити сертифікатами X.509/PKI, а приватні — зберігати в HSM/KMS із двофакторним доступом.
